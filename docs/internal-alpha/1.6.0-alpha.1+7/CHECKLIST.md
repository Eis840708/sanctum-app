# SANCTUM Internal Alpha｜測試 Checklist

測試者：__________　裝置／Android：__________　日期：__________　語言：__________

每項填 `PASS`、`FAIL` 或 `BLOCKED`；只可使用合成資料。

## 核心流程

- [ ] 首次建立 v3 Vault；生成的隨機詞語可完整記錄並再次輸入。
- [ ] 正確詞語可解鎖；錯誤詞語被拒絕，錯誤訊息不洩漏原因細節。
- [ ] 靜止 60 秒後自動上鎖；重新解鎖成功。
- [ ] 解鎖後沒有 crash、白屏或返回鎖定頁循環。
- [ ] 手動鎖定成功；鎖定後看不到 Vault 內容。
- [ ] 開啟中的新增／編輯視窗遇到鎖定會關閉，鎖定後不能寫入。
- [ ] 生物辨識啟用成功；鎖定後可用真指紋／面容解鎖。
- [ ] 生物辨識失敗時保持鎖定，並可改用主密碼／隨機詞語。

## 功能 CRUD

- [ ] 密碼：新增→檢視→顯示／隱藏→編輯→刪除。
- [ ] 密碼產生器可產生內容並儲存；重開記錄內容一致。
- [ ] 日記：新增→搜尋→編輯→刪除；首頁／搜尋不意外洩漏標題。
- [ ] 財務：新增收入及支出→核對結餘→編輯→刪除。
- [ ] 關閉並重開 App 後，已儲存的合成資料仍正確。

## 備份與恢復

- [ ] 匯出 SNCB3 備份成功。
- [ ] 使用備份還原成功，記錄數量及內容一致。
- [ ] 錯密碼／損毀備份顯示統一錯誤，原有資料不受影響。
- [ ] Shamir 逐片產生／分發，介面沒有「一次分享全部碎片」。
- [ ] 達門檻碎片可恢復並設定新密碼；成功後強制重新鎖定。
- [ ] 舊密碼失效，新密碼可解鎖，資料完整。

## i18n 與 UI

每種語言至少走一次鎖定頁、首頁、密碼、日記、財務、設定、備份及 Shamir：

- [ ] 繁港 `zh`
- [ ] 繁台 `zh-TW`
- [ ] 簡中 `zh-SC`
- [ ] English `en`
- [ ] 日本語 `ja`
- [ ] 한국어 `ko`

每種語言檢查：

- [ ] 無錯字、錯詞或術語不一致；`Vault` 保留英文。
- [ ] 無繁體中文殘留於其他語言。
- [ ] 切換語言後，按鈕／生物辨識標籤即時更新。
- [ ] 無文字截斷、溢出、重疊、豆腐字或不自然標點。
- [ ] 深色主題核心畫面可讀；設定頁另檢查淺色對照。

## 安全表現與收尾

- [ ] 正式版截圖／錄屏／ADB screencap 為全黑（正常）。
- [ ] 複製敏感內容後，逾時／鎖定／切到背景會清除；不誤刪之後複製的新內容。
- [ ] logcat、錯誤訊息及通知沒有合成密碼、恢復碎片或 Vault 內容。
- [ ] v3 transfer 顯示停用／不可用，不能誤入不完整流程。
- [ ] 已刪除全部合成記錄、測試備份及碎片。
- [ ] 所有 FAIL 已使用 bug template 登記及分級。

最終結論：`PASS`／`CONDITIONAL PASS`／`FAIL`
